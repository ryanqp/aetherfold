# Commander words, for people who do not play Magic

Aetherfold is a two-player Commander table. These are the words the screen and the docs use.

| Word | Meaning here |
|---|---|
| Commander | The signature creature of a deck. It starts in the command zone and can be cast from there. Casting it again costs {2} more each time. |
| Library | The deck you draw from. |
| Hand | Cards you can play. |
| Battlefield | Cards in play. Creatures, lands, and other permanents sit here. |
| Graveyard | Discard pile. Destroyed creatures and resolved instants and sorceries go here. |
| Exile | Cards removed from the game. |
| Stack | Spells that have been cast and have not resolved yet. The top one resolves when both players pass. |
| Mana | Currency from lands and some creatures. `{R}` is one red mana. `{1}` is one mana of any color. |
| Tap | Turn a permanent sideways to use it. A tapped land cannot make mana again until your next turn. |
| Summoning sickness | A creature cannot attack, or use an ability that taps it, on the turn it entered. |
| Instant | A spell you can cast on either player's turn, including in response to another spell. |
| Sorcery | A spell you can cast on your turn, when the stack is empty, in a main phase. |
| Life | Both players start at 40. The game ends when a player reaches 0. |
| Combat | Attackers are declared, the opponent may block, then damage happens. |
| Pass | Decline to do anything else this step. |
| Mulligan | Shuffle an opening hand back and draw a new one. |
| Token | A permanent created by a spell, such as a 1/1 Soldier. It was never a card in the deck. |

Card names, rules text, and art belong to Wizards of the Coast. This table is an unofficial fan project.
